# مرصاد AI — واجهة سطح المكتب لنظام Windows

تمت إضافة مشغّل سطح مكتب مستقل باسم MERSAD_Desktop.exe.

## ما الذي يتغير؟
- تظهر لوحة مرصاد داخل نافذة Windows مستقلة بعنوان مرصاد الذكي.
- لا يتم فتح Chrome أو Edge كنافذة متصفح خارجية.
- يستمر محرك الذكاء الاصطناعي الحالي في إدارة الكاميرات وYOLO وEasyOCR وقاعدة البيانات.
- تتواصل النافذة مع المحرك عبر عنوان Loopback محلي محمي برمز جلسة عشوائي.
- عند إغلاق نافذة مرصاد، يطلب المشغّل من المحرك الإغلاق المنظم وتحرير الكاميرات.

## المتطلب
يحتاج Windows إلى Microsoft Edge WebView2 Runtime. هذا محرك عرض مضمّن للتطبيقات، وليس اعتماداً على فتح متصفح Edge نفسه.
صفحة Microsoft الرسمية: https://developer.microsoft.com/en-us/microsoft-edge/webview2/

على Windows 11 يكون WebView2 Runtime مضمناً عادةً، بينما يجب التحقق من وجوده على Windows 10. المشغّل يفحص سجل Windows ويعرض رسالة واضحة عند غيابه.

## تشغيل نسخة المصدر
من مجلد MERSAD_AI_Preview_0.1 وبعد تثبيت المتطلبات:
python desktop_shell.py

لتشغيل المحرك مباشرة دون النافذة المكتبية (وضع الصيانة):
python mersad_live.py --no-window

## اختبار حزمة Windows
بعد بناء التوزيعة:
dist\MERSAD_AI\MERSAD_Desktop.exe --self-test

يجب توزيع المجلد الكامل dist\MERSAD_AI وعدم فصل MERSAD_Desktop.exe عن MERSAD_AI.exe وملفات التشغيل والنماذج.

## حدود النسخة الحالية
هذه نافذة سطح مكتب أصلية تستضيف لوحة HTML الحالية عبر WebView2. لم يُعَد بناء كل مكوّنات اللوحة بعد كعناصر WinUI/WPF أصلية. اختبار CI يتحقق من تجميد الحزمة وتكاملها؛ يلزم أيضاً اختبار فتح النافذة وإغلاقها على جهاز Windows فعلي قبل اعتماد الإصدار الميداني.
