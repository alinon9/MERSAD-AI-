# دليل ربط الكاميرات بمرصاد — نسخة المعرض

## مصادر الكاميرا
- USB/Webcam: أدخل رقم الجهاز في Windows مثل 0 أو 1.
- هاتف Android عبر الشبكة: استخدم تطبيق بث كاميرا مثل IP Webcam، شغّل الخادم المحلي، وأدخل رابط MJPEG الذي يعرضه التطبيق (غالباً http://PHONE_IP:8080/video).
- هاتف Android عبر كابل USB: فعّل USB tethering ثم استخدم تطبيق بث الكاميرا وعنوان البث الذي يعرضه. هذا اتصال شبكي عبر USB وليس UVC مباشراً.
- USB Webcam mode / virtual webcam: إذا كان الهاتف والطراز وتعريف Windows يدعمون ظهور الهاتف ككاميرا، اختر رقم الجهاز الذي يظهر في Windows.
- كاميرا IP أو DVR/NVR: أدخل رابط RTSP/RTSPS أو HTTP/MJPEG الذي يتيحه جهاز التسجيل.

## إعداد المعرض
1. افتح مرصاد على الكمبيوتر.
2. وصّل الهاتف والكمبيوتر على شبكة Wi-Fi واحدة، أو استخدم USB tethering.
3. افتح تطبيق بث الكاميرا على الهاتف وانسخ رابط الفيديو إلى شاشة «ربط كاميرا».
4. لكاميرا المراقبة، استخرج رابط RTSP من إعدادات الكاميرا أو NVR وأدخله.
5. انتظر تأكيد وصول الإطارات قبل بدء العرض.

## أمثلة لمسارات RTSP (تختلف حسب الطراز)
- Hikvision: rtsp://USER:PASSWORD@HOST:554/Streaming/Channels/101
- Dahua: rtsp://USER:PASSWORD@HOST:554/cam/realmonitor?channel=1&subtype=0
- Uniview: راجع إعدادات الطراز للحصول على المسار الصحيح.

## حدود مهمة
- USB UVC المباشر ليس مضموناً لكل هواتف Android؛ يعتمد على الهاتف وإصدار النظام وتعريف Windows.
- USB tethering مع بث MJPEG بديل عملي لكنه يتطلب تطبيق بث على الهاتف.
- DVR/NVR يجب أن يوفر RTSP/HTTP وأن يكون الكمبيوتر قادراً على الوصول إليه.
- هذه الإضافة لا تدّعي اكتشاف ONVIF تلقائياً؛ أدخل رابط البث الذي يوفره الجهاز.
- استخدم فقط كاميرات لديك تصريح بالوصول إليها، واحمِ بيانات الدخول.
