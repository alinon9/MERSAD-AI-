# ابدأ من هنا — دليل التشغيل والبناء السريع لنظام مرصاد الذكي (MERSAD AI V7.1 — Stage 15)

صُممت هذه الحزمة لتحصل على النسخة التنفيذية الكاملة **`MERSAD_AI.exe`** لنظام **Windows 10/11 (64-bit / x64)** مع جميع ملفات **`DLL`** والنماذج الأربعة (**YuNet**, **SFace**, **YOLOv8n**, **EasyOCR**) بضغطة زر واحدة، دون الحاجة لإعدادات يدوية معقدة.

---

## الخيار الأول (الموصى به): البناء السحابي عبر GitHub Actions وتنزيل `MERSAD_AI.exe` تلقائياً بضغطة واحدة

لا يتطلب هذا الخيار تثبيت Python أو مكتبات الذكاء الاصطناعي على جهازك؛ حيث يقوم خادم Windows السحابي في GitHub Actions ببناء البرنامج وتنزيل النماذج الأربعة واختبارها ثم إرجاع مجلد التشغيل الجاهز إلى جهازك تلقائياً:

1. **فك الضغط**: استخرج محتويات الحزمة `MERSAD_AI_V7_1_FINAL_BUILD_PACKAGE.zip` إلى مجلد على جهازك (مثلاً `C:\MERSAD_AI_STAGE15\`).
2. **المتطلبات البسيطة**:
   - وجود **Git for Windows** ([git-scm.com](https://git-scm.com/download/win)).
   - وجود **GitHub CLI (`gh`)** (يمكن تثبيته بالأمر `winget install --id GitHub.cli` أو من [cli.github.com](https://cli.github.com/)).
3. **التشغيل بضغطة واحدة (يدعم التشغيل الأول والتشغيل المتكرر بأمان)**:
   - انقر نقراً مزدوجاً على الملف:
     **`PUSH_TO_GITHUB_AND_BUILD.bat`**
4. **ماذا سيفعل السكربت تلقائياً؟**
   - يتحقق من تسجيل دخولك إلى GitHub عبر المتصفح بأمان (دون كتابة أي كلمة مرور أو Token داخل السكربت).
   - يستنسخ أو يحدّث المستودع `https://github.com/alinon9/MERSAD-AI-` في مجلد عمل متزامن (`.git_build_worktree`) فوق التاريخ الفعلي للمستودع (لتجنب خطأ `unrelated histories` ولدعم التشغيل المتكرر دون فقد أي ملفات موجودة).
   - يرفع التحديثات إلى فرع البناء `release/v7.1-stage15-win-x64` بدون `Force Push`، ويتأكد من تسجيل `.github/workflows/windows-build.yml` بأمان على الفرع الافتراضي دون استبدال ملفات `main`.
   - يتتبع عملية البناء المرتبطة حصرياً ببصمة الـ commit الحالي (`LOCAL_HEAD_SHA`) دون إطلاق عمليتي بناء مكررتين لنفس التحديث ودون التقاط عملية بناء قديمة بالخطأ.
   - فور نجاح البناء، ينزّل الحزمة `MERSAD_AI_Windows_x64_Distribution` ويستخرجها في:
     **`MERSAD_AI_RELEASE\MERSAD_AI\MERSAD_AI.exe`**
   - يتحقق فعلياً من وجود النماذج الأربعة وملفات `.dll` وملفات التشغيل، ويشغّل `MERSAD_AI.exe --verify-models` و `MERSAD_AI.exe --verify` مع فحص رمز الخروج (`!ERRORLEVEL!`) قبل إعلان النجاح.

## الخيار الثاني (البديل المحلي الكامل): بناء `MERSAD_AI.exe` مباشرةً على جهازك Windows

إذا كنت تفضل بناء النسخة التنفيذية محلياً على جهازك دون استخدام GitHub Actions:

1. **تثبيت Python المتوافق**:
   - ثبّت **`Python 3.11 (64-bit)`** من الموقع الرسمي [python.org/downloads](https://www.python.org/downloads/) وتأكد من تفعيل خيار **`Add python.exe to PATH`** أثناء التثبيت.
   - *(ملاحظة: السكربت يكتشف `Python 3.11 64-bit` تلقائياً عبر `py -3.11-64` حتى لو كان لديك Python 3.13 أو 3.14 مثبتاً على الجهاز).*
2. **التشغيل بضغطة واحدة**:
   - انقر نقراً مزدوجاً على الملف:
     **`BUILD_EXE.bat`**
3. **ماذا سيفعل السكربت تلقائياً؟**
   - ينشئ البيئة الافتراضية `venv` ويثبّت جميع المكتبات المثبتة (`PyTorch 2.5.1`, `OpenCV 4.11`, `Ultralytics YOLOv8`, `EasyOCR`, `Scikit-Learn`, `PyInstaller 6.11.1`) ويعالج تعارضات `opencv-python-headless`.
   - ينزّل النماذج الأربعة (`yunet.onnx`, `sface.onnx`, `yolov8n.pt`, وأوزان `EasyOCR` العربية والإنجليزية) ويتحقق منها.
   - يشغّل الاختبارات الآلية (`selftest.py` — 201 اختباراً) للتأكد من سلامة جميع وظائف المرحلة 15.
   - يبني الملف التنفيذي ويختبره، ويجهز مجلد التوزيع الكامل في:
     **`dist\MERSAD_AI\MERSAD_AI.exe`**

## ملاحظة أمنية حول التحقق من النماذج الأربعة

- **YuNet (`yunet.onnx`) و SFace (`sface.onnx`)**: يتم التحقق منهما مقابل **بصمات `SHA-256` ثابتة وموثوقة مدمجة مسبقاً داخل الكود المصدري** (`MODEL_SHA256`).
- **YOLOv8n (`yolov8n.pt`)**: يخضع لفحص بنيوي لأرشيف PyTorch وفحص أمان ساكن لـ Pickle bytecode (`_scan_pt_pickle_safety`) قبل حفظه، ثم تُسجَّل بصمته `SHA-256` بعد أول تنزيل ناجح (`yolov8n.pt.sha256` و `.trusted_models.json`) لمنع أي تلاعب أو تلف لاحق (ويمكن تمرير بصمة مسبقة عبر `MERSAD_YOLO_SHA256` للتحقق الصارم قبل الحفظ).
- **EasyOCR (`models/easyocr/*.pth`)**: يخضع لفحص بنيوي (`verify_easyocr_dir`) يتحقق من وجود وزني الكاشف والمميز (`>= 2` ملفات `.pth` بحجم `>= 500 KB`) وسلامة ترويسة PyTorch وخلو المجلد من ملفات التنزيل الناقصة (`.part`).

## طريقة تشغيل البرنامج بعد انتهاء البناء

سواء حصلت على المجلد من الخيار الأول (`MERSAD_AI_RELEASE\MERSAD_AI\`) أو من الخيار الثاني (`dist\MERSAD_AI\`):

- **للتشغيل القياسي على جهازك**: انقر نقراً مزدوجاً على **`RUN.bat`** (أو شغّل **`MERSAD_AI.exe`** مباشرةً).
- **للتشغيل مع فتح لوحة التحكم للهواتف والأجهزة على نفس شبكة Wi-Fi**: انقر نقراً مزدوجاً على **`RUN_LAN.bat`**.
- **للتحقق من سلامة النماذج والسلسلة الجنائية وتقرير الجاهزية**: انقر نقراً مزدوجاً على **`VERIFY_AUDIT.bat`**.

### ملاحظة مهمة عند نقل البرنامج إلى جهاز Windows آخر
البرنامج مبني بنمط المجلد المتكامل (`--onedir`) لضمان سرعة الإقلاع وعدم فك ضغط النماذج الثقيلة في كل مرة؛ لذلك عند نقله إلى كمبيوتر آخر لا يحتاج إلى Python أو إنترنت، **انسخ مجلد `MERSAD_AI` بالكامل** (بما يحتويه من `MERSAD_AI.exe` ومجلد `models\` وملفات `.dll`) ولا تنسخ ملف `MERSAD_AI.exe` بمفرده.
