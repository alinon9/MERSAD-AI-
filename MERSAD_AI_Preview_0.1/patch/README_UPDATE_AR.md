# تحديث مرصاد التراكمي — المراحل 1 و2 و3

هذه حزمة تحديث للنسخة الجاهزة EXE وليست نسخة توزيع كاملة.

## محتويات التحديث
- MERSAD_AI.exe: محرك مرصاد مع إصلاحات ALPR وربط الكاميرات ودعم واجهة سطح المكتب.
- MERSAD_Desktop.exe: مشغّل نافذة Windows المستقلة عبر WebView2.
- dashboard.html وcamera-connect.js: ملفات واجهة ربط الهاتف وUSB وIP/CCTV.

## طريقة التطبيق
1. أغلق مرصاد بالكامل.
2. فك ضغط ملف التحديث.
3. شغّل APPLY_UPDATE.bat.
4. أدخل المسار الكامل للمجلد الحالي الذي يحتوي على MERSAD_AI.exe، وليس المجلد الأب.
5. انتظر رسالة SUCCESS.
6. شغّل MERSAD_Desktop.exe.

ينشئ المثبّت نسخة احتياطية من الملفات الأربعة التي سيستبدلها. لا يلمس مجلد models أو قاعدة البيانات أو الأدلة أو الإعدادات أو السجلات.

## متطلب الواجهة
يتطلب تشغيل الواجهة وجود Microsoft Edge WebView2 Runtime:
https://developer.microsoft.com/en-us/microsoft-edge/webview2/

## ملاحظات
- هذه الحزمة مخصصة لنسخة Windows x64 المبنية من نفس خط إصدار MERSAD PREVIEW 0.1.
- لا تطبقها فوق إصدار مختلف أو مجلد لا يحتوي MERSAD_AI.exe.
- لا تحذف النسخة القديمة أو النسخة الاحتياطية حتى تنجح اختبارات التشغيل والكاميرا.
- نجاح CI لا يغني عن اختبار الكاميرا والنافذة فعليًا على جهازك.
