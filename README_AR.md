# مرصاد AI — MERSAD AI

هذا المستودع مجهز لبناء حزمة Windows x64 عبر GitHub Actions من الأرشيف المصدر.

## بدء البناء

1. ارفع الملف `MERSAD_AI_FIXED_5.zip` إلى جذر هذا المستودع (وليس داخل مجلد فرعي).
2. بعد رفعه، سيبدأ سير العمل `Build MERSAD AI Windows EXE` تلقائيًا. ويمكن تشغيله يدويًا من تبويب **Actions** ثم **Build MERSAD AI Windows EXE** ثم **Run workflow**.
3. انتظر حتى تنتهي خطوات الاختبار والبناء. نجاح البناء وحده لا يغني عن تجربة البرنامج على جهاز Windows فعلي.
4. افتح تشغيل سير العمل الناجح، ثم نزّل العنصر **MERSAD_AI_Windows_x64_Distribution** من قسم **Artifacts**.
5. فك ضغط الـ artifact وانقل مجلد `MERSAD_AI` كاملًا. لا تنقل ملف EXE وحده؛ الحزمة تعتمد على ملفات DLL والنماذج الموجودة بجانبه.

## ملاحظات

- المستودع خاص. لا تضع مفاتيح API أو كلمات مرور أو بيانات شخصية في الأرشيف.
- GitHub Actions يبني من المصدر الموجود داخل `MERSAD_AI_FIXED_5.zip`. تأكد أن هذا هو الإصدار الذي تريد بناءه.
- يتطلب البناء تنزيل المكتبات والنماذج على خادم GitHub Actions؛ لا يلزم تنزيلها على اللابتوب من أجل عملية البناء.
- قد يفشل البناء إذا تعذر تنزيل المكتبات أو النماذج، أو إذا فشلت الاختبارات. راجع سجلات التشغيل لمعرفة السبب.
