# نظام مرصاد الذكي — MERSAD AI (حزمة الإصلاحات التشغيلية V7.1)

نظام مراقبة وتحليل مروري وأمني يعمل محلياً، ويركّز هذا التحديث على استكمال مركز القيادة والتحليلات التشغيلية، وسجل موثوقية الكاميرات، ومراقبة الانقطاع والتعافي، إلى جانب قدرات الرصد الحالية. يرصد المركبات والشاحنات (`YOLOv8n`) ويقرأ اللوحات العربية واللاتينية (`EasyOCR`) ويطابق الوجوه المسجّلة بموافقة صريحة (`YuNet` + `SFace`)، ويحلل المسارات والاتجاهات والشذوذ عبر الكاميرات المتعددة، ويرسل تنبيهات مدعومة بالصور إلى غرفة العمليات عبر تيليجرام مع اشتراط **التأكيد البشري** قبل توجيه الدوريات.

---

## 1. متطلبات التشغيل والتثبيت

* **نظام التشغيل**: `Windows 10 / 11 (64-bit / x64)` أو `Linux x86_64`.
* **إصدار Python المرجعي**: **`Python 3.11 (64-bit)`**؛ سكربت بناء EXE يتطلب هذا الإصدار تحديدًا لمطابقة الإصدارات المثبتة.
* **الاتصال بالإنترنت**: مطلوب **مرة واحدة فقط** أثناء الإعداد الأول (`setup.bat` / `prefetch.py`) لتثبيت المكتبات وتنزيل النماذج والتحقق من بصماتها؛ يعمل النظام بعد ذلك بدون إنترنت (`Offline`) بالكامل.

---

## 2. طريقة الإعداد والتشغيل على Windows

### أ) التشغيل من الكود المصدري (مع إعداد تلقائي للبيئة والنماذج)
1. فك ضغط ملف `MERSAD_AI_V7_OPERATIONAL_ENHANCED.zip` في مجلد محلي.
2. انقر نقراً مزدوجاً على **`RUN.bat`** (أو **`RUN_LAN.bat`** لتفعيل الوصول من الجوالات على نفس الشبكة المحلية).
   - سيقوم `setup.bat` تلقائياً بإنشاء البيئة الافتراضية `venv`، وتثبيت `torch==2.5.1` و `torchvision==0.20.1` والحزم المثبتة من `requirements.txt` و `constraints-win-x64.txt`، وإزالة أي نسخة `headless` متعارضة من OpenCV، وتنزيل النماذج والتحقق من سلامتها عبر `prefetch.py`، ثم كتابة ختم الجاهزية المشفر `venv\.ready`.
   - بعد التحقق من سلامة جميع المكونات عبر `check_install.py --strict`، يبدأ `mersad_live.py` ويفتح لوحة التحكم.

### ب) بناء حزمة التوزيع `dist\MERSAD_AI\MERSAD_AI.exe`
1. شغّل **`BUILD_EXE.bat`**.
2. بعد اكتمال الفحوصات والبناء، سينتج المجلد **`dist\MERSAD_AI\`** شاملاً `MERSAD_AI.exe` والمكتبات المرفقة ومجلد `models\` وسكربتات التشغيل (`RUN.bat`, `RUN_LAN.bat`, `VERIFY_AUDIT.bat`). يفحص السكربت سلسلة التدقيق والأوزان المرفقة بعد البناء.
3. لنقل البرنامج إلى جهاز Windows آخر لا يحتوي على Python، انسخ مجلد **`dist\MERSAD_AI\` بالكامل**.

## 3. مسارات حفظ البيانات والموارد

يفصل النظام تلقائياً بين الموارد الثابتة القابلة للقراءة فقط ومجلد بيانات المستخدم القابل للكتابة:
* **الموارد الثابتة (`dashboard.html` و `models/`)**: تُقرأ من مجلد التطبيق أو التوزيع (`INSTALL_DIR` / `BUNDLE_DIR`).
* **بيانات التشغيل والأمن (`APPDIR`)**:
  - إذا كان مجلد التطبيق قابلاً للكتابة، تُحفظ البيانات فيه.
  - إذا كان مجلد التثبيت محمياً للقراءة فقط (مثل `C:\Program Files\MERSAD_AI\`)، يحفظ النظام البيانات تلقائياً في `%LOCALAPPDATA%\MERSAD_AI\` (أو `~/.local/share/mersad_ai/` على Linux).
  - تشمل ملفات `APPDIR`: قاعدة البيانات `mersad.db`، مفتاح التعمية `.mersad_hmac.key` (`0600`)، ملف الأسرار `.mersad_secrets.json` (`0600`)، صور الأدلة `evidence/`، الأرشيف `evidence_archive/`، وسجل التشغيل `mersad.log`.

## 4. تشغيل الاختبارات وتشخيص الأخطاء

```bash
# 1. تشخيص البيئة والمكتبات والنماذج (تقرير مفصّل مع خطوات الإصلاح لكل عنصر)
python check_install.py

# 2. فحص صارم لجميع المتطلبات والنماذج (يرجع 1 عند نقص أي نموذج أو مكتبة)
python check_install.py --strict

# 3. تشغيل حزمة الاختبارات الآلية الشاملة (136 فحصًا في هذه النسخة)
python selftest.py

# 4. تشغيل الاختبارات مع حجب scikit-learn لاختبار البديل الإحصائي StatForest
MERSAD_BLOCK_SKLEARN=1 python selftest.py

# 5. التحقق الجنائي من سلامة سلسلة التدقيق (SHA-256) وجميع صور الأدلة النشطة والمؤرشفة
python mersad_live.py --verify

# 6. فحص وجود وسلامة النماذج المحلية (لا ينزّل نماذج؛ يرجع 2 عند النقص/التلف)
python mersad_live.py --verify-models
```


## 7. إضافات V7 التشغيلية

- **مركز القيادة**: اتجاه رصد ساعي لمدة 24 ساعة، مقارنة الفترة السابقة، توزيع الفئات والثقة، ملخص التنبيهات والتوجيهات، وصندوق توصيات تشغيلية قابلة للتفسير.
- **موثوقية الكاميرات**: سجل دائم لتغيّر الحالة (`online` / `reconnecting` / `offline`)، وفترات تشغيل/انقطاع مرصودة، وتعداد الانقطاعات والتعافي، مع عرض 24 ساعة أو 7 أيام أو 30 يوماً.
- **تصدير CSV آمن**: ترميز UTF-8 مع BOM، ومعالجة القيم التي قد تفسرها برامج الجداول كصيغ. ملف التحليلات يعرض مقاييس مجمعة فقط ولا يحتوي قيم اللوحات أو أسماء الأشخاص أو مسارات الأدلة.
- **واجهات محمية**: `/api/analytics`, `/api/analytics/export.csv`, `/api/camera-health`, `/api/camera-health/export.csv` تخضع لمصادقة لوحة التحكم.
- **تثبيت أكثر موثوقية**: فحص صلاحيات مجلد التثبيت في POSIX لا يعتمد على نجاح الكتابة بصلاحيات root وحدها، وتضمين الوحدات الجديدة في البناء والتشخيص.

**ملاحظة مصدر مهمة:** لم يُرفق في هذه المحادثة أرشيف كود V6 نفسه؛ المرفق كان تقرير الاختبار وملاحظات الإصدار. لذلك بُنيت حزمة التحسين هذه على أرشيف المصدر المتاح `MERSAD_AI_FIXED_5.zip`، وأُعيد تنفيذ مركز القيادة وفق ملاحظات V6 المرفقة، مع إضافة سجل موثوقية الكاميرات. لا تدّعي هذه الحزمة أنها تحتفظ بتغييرات غير مرئية في شجرة مصدر V6 غير المرفقة.

## 8. نقاط التحقق الإصدار V7.1

- اختبارات التزامن `P0-E` وعزل الكاميرات `P1-C` تُعاد عدة مرات داخل `BUILD_EXE.bat` وWindows CI حتى تكشف النتائج المتقطعة.
- `--verify-models` يتحقق من ملفات YuNet وSFace وYOLOv8n وEasyOCR دون تنزيلها أثناء التشغيل، ويُعطي رمز خروج غير صفري إذا فقد أي ملف أو تلف.
- ملف قاعدة البيانات يُفضّل وضعه على قرص محلي؛ اكتشاف مسارات UNC/الأقراص الشبكية يختار journal mode بديلًا متى أمكن، لكنه لا يجعل مشاركة قاعدة بيانات SQLite عبر الشبكة خيارًا موصى به.
- لا تُعد هذه الحزمة موثّقة على Windows إنتاجيًا حتى تنجح Windows CI واختبار الكاميرا الفعلية واختبار Telegram الحقيقي.
